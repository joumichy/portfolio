# Resume sharing by QR code

Instance non identifiée. Working tree: `projects/portfolio`, branch `main`,
base `756737b`. Changes are local, uncommitted and not deployed.

- Added “Partager mon CV” to the hero using the existing Button component.
  A native modal dialog covers the viewport, uses the existing slate/indigo
  styling and displays the requested French title and subtitle, a large black
  QR on white, and a native close button. Dynamic viewport sizing, safe-area
  padding and a compact-height layout support mobile screens. Opening locks
  background scrolling; closing releases it. Native dialog semantics own focus
  containment, Escape dismissal and focus restoration.
- QR SVG is generated locally during the Astro build with `qrcode-generator`
  (development dependency, no dependencies of its own), medium error correction
  and a four-module quiet zone. No QR library is shipped to the browser.
- `src/data/resume.ts` owns the existing `/resume.pdf` path, shared by the navbar
  and QR component. The public origin comes from the existing Astro `site`
  configuration. Replace `public/resume.pdf` at the same path when updating the
  CV; no additional page, PDF copy or external sharing service was introduced.
- Verification: `npm run build` generated all nine pages; `astro-check` reported
  zero errors (one existing unused-variable hint in DiagramContainer);
  `git diff --check` passed. Apple Vision independently decoded the SVG extracted
  from built HTML after rasterization at 256, 288 and 352 pixels, always yielding
  `https://john-on-tech.com/resume.pdf`. Public and local HTTP requests returned
  200 with `application/pdf`; public, source and built PDFs have identical SHA-256.
- Limitations: no interactive browser workflow, mobile visual review, console
  or browser-network review, regression workflow, or physical-phone camera scan
  was completed. Computer use reports browser access disabled in Work settings
  and the Mac locked; opening an integrated-browser tab was also rejected.
  Browser access/unlock was requested while implementation continued.
